# PROJECT-3 - GLAMIRA

A modern, responsive web showcase for GLAMIRA jewelry collection.

## Overview

This project implements a beautiful and interactive jewelry showcase website for GLAMIRA, featuring:

- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- **Modern UI**: Elegant gradient designs and smooth animations
- **Interactive Elements**: Product cards with hover effects and click interactions
- **Featured Collection**: Showcase of premium jewelry items including rings, necklaces, earrings, and bracelets

## Features

- Clean and modern user interface
- Interactive product cards with hover animations
- Smooth scroll effects and transitions
- Responsive grid layout
- Product detail viewing functionality

## Getting Started

Simply open `index.html` in your web browser to view the GLAMIRA jewelry showcase.

### Files Structure

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Interactive features and animations

## Technologies Used

- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript
- Responsive Grid Layout

## About GLAMIRA

GLAMIRA represents elegance, quality, and timeless beauty. This showcase demonstrates a modern approach to presenting premium jewelry collections online.
